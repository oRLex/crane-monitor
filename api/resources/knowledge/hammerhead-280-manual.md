# Hammerhead 280 — operator manual extract

> Demo library document for the fictional Hammerhead 280 model.

## Main data

- Rated load moment: 280 t·m
- Maximum load: 12 t (up to 23 m radius)
- Jib length: 65 m, tip load 3.1 t
- The tower head and ties make this crane more sensitive to side wind than a flat-top; observe the wind warning strictly.

## Parking for out-of-service

Park the trolley at 20 m radius, release the slew brake, hook up. In-service wind limit 20 m/s; erection and dismantling only below 12 m/s.
