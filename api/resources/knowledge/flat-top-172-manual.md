# Flat-top 172 — operator manual extract

> Demo library document for the fictional Flat-top 172 model.

## Main data

- Rated load moment: 172 t·m
- Maximum load: 8 t (up to 21.5 m radius)
- Jib length: 60 m, tip load 2.4 t
- Hoist speed: up to 80 m/min (light loads)

## Parking for out-of-service

Park the trolley at 15 m radius with the hook at the top position, release the slew brake. Maximum in-service wind is 20 m/s.

## Daily checks

Limit switches (hoist, trolley, slew), load moment limiter test with a known test weight weekly, anemometer free running.
