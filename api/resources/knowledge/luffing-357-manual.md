# Luffing 357 — operator manual extract

> Demo library document for the fictional Luffing 357 model.

## Main data

- Rated load moment: 357 t·m
- Maximum load: 20 t
- Jib length: 55 m
- Luffing jibs are used on congested sites; the jib angle changes the radius, so the load moment changes while luffing even if the load does not.

## Out-of-service

A luffing crane is parked with the jib at the minimum angle specified for out-of-service (typically 15°) and the slew brake released. Never leave the jib steep in storm wind.

## Overload behaviour

Luffing out increases the radius and the moment. When the limiter warns at 90 %, stop luffing out; luffing in reduces the moment.
